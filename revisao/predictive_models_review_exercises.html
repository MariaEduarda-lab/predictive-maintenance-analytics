How to use this worksheet

Solve it first without consulting the material. Then explain aloud why your answer makes sense. In data science, justifying a decision matters as much as selecting an option.

Assertion–reason convention

  1. Both statements are true, and the reason explains the assertion.
  2. Both are true, but the reason does not explain the assertion.
  3. The assertion is true, and the reason is false.
  4. The assertion is false, and the reason is true.
  5. Both statements are false.

Open-answer guide

21. Matrix and metrics

TP=16, FN=4, FP=10, TN=70. Accuracy=86%; precision≈61.5%; recall=80%; F1≈69.6%.

22–24. Core concepts

KNN: nearest A, B, C → Pink by 2–1. K-Means: {1,2,3} → 2 and {8,9,10} → 9. Regression predicts continuous values; classification predicts categories or class probabilities.

25–27. Features and code

Strong Titanic ideas include FamilySize, IsAlone, Title, FarePerPerson, HasCabin, Deck, ticket-group size, and age bands. Preprocessing must be fitted only on training data. Metric formulas must handle zero denominators.

28–30. Reasoning criteria

Reward coherent trade-offs, validation without test leakage, a metric aligned with error cost, features available at prediction time, a meaningful baseline, and ethical or operational risk analysis.
