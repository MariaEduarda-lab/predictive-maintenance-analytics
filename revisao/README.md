# Predictive Models — English Review

This folder contains the identity-neutral English review of the predictive models module. The materials retain the pink, purple, and lilac palette while removing the Grace Hopper community branding.

## Files

- [predictive_models_review_slides.html](./predictive_models_review_slides.html) — interactive 28-slide module review.
- [predictive_models_review_slides.pdf](./predictive_models_review_slides.pdf) — widescreen PDF with one page per slide.
- [predictive_models_review_exercises.html](./predictive_models_review_exercises.html) — printable worksheet with 30 questions and an answer key.
- [predictive_models_review_exercises.pdf](./predictive_models_review_exercises.pdf) — A4 PDF version of the exercise worksheet.

## Topics

Data cleaning, EDA, feature engineering, leakage, supervised and unsupervised learning, Logistic Regression, Decision Trees, Random Forest, KNN, Naive Bayes, confusion matrices, classification and regression metrics, overfitting, validation, recommendation systems, K-Means, Elbow, Silhouette, hierarchical clustering, DBSCAN, and distance metrics.

## Slide controls

Use the arrow keys or Space to navigate, **F** for fullscreen, and **O** for overview mode.
